# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузку конфигурации можно реализовать из различных источников, например: файлов, переменных окружения, баз данных и других.

## Поддерживаемые источники конфигурации

Приложение поддерживает следующие способы конфигурации (в порядке приоритета, от максимального к минимальному):

1. **Переменные окружения** - наивысший приоритет
2. **Флаги командной строки**
3. **JSON файл конфигурации** - используется как базовая конфигурация
4. **Значения по умолчанию**

### Флаги командной строки

- `-a` - адрес HTTP-сервера (по умолчанию ":8080")
- `-b` - базовый URL (по умолчанию "http://localhost:8080")
- `-c` / `-config` - путь к файлу JSON конфигурации
- `-d` - строка подключения к базе данных PostgreSQL
- `-f` - путь к файлу хранилища (по умолчанию "/var/lib/url-shorter/short-url-db.json")
- `-s` - включить HTTPS сервер (флаг без значения)
- `-audit-file` - путь к файлу аудита
- `-audit-url` - URL удаленного сервера аудита

### Переменные окружения

- `SERVER_ADDRESS` - аналог флага `-a`
- `BASE_URL` - аналог флага `-b`
- `FILE_STORAGE_PATH` - аналог флага `-f`
- `DATABASE_DSN` - аналог флага `-d`
- `ENABLE_HTTPS` - аналог флага `-s` (значения: "true", "1")
- `CONFIG` - путь к файлу JSON конфигурации
- `AUDIT_FILE` - аналог флага `-audit-file`
- `AUDIT_URL` - аналог флага `-audit-url`

### JSON конфигурация

Путь к файлу конфигурации можно указать через флаг `-c`/`-config` или переменную окружения `CONFIG`.

Пример файла `config.json`:

```json
{
  "server_address": "localhost:8080",
  "base_url": "http://localhost",
  "file_storage_path": "/path/to/file.db",
  "database_dsn": "postgres://user:password@localhost/dbname",
  "enable_https": true,
  "audit_file": "/var/log/audit.log",
  "audit_url": "http://audit.example.com"
}
```

Все поля в JSON являются опциональными. Если поле не указано, будет использовано значение из флага или переменной окружения (если они заданы), либо значение по умолчанию.

## Примеры использования

### Использование только флагов

```bash
./shortener -a :8080 -b http://example.com
```

### Использование JSON конфигурации

```bash
./shortener -c /etc/shortener/config.json
```

### Использование JSON конфигурации с переопределением через переменные окружения

```bash
export SERVER_ADDRESS=":9090"
export CONFIG="/etc/shortener/config.json"
./shortener
```

В этом случае адрес сервера будет взят из переменной окружения (`:9090`), а остальные параметры - из JSON файла.

### Комбинированное использование

```bash
export DATABASE_DSN="postgres://prod/db"
./shortener -c config.json -s
```

В этом случае:

- `DATABASE_DSN` будет взят из переменной окружения
- Флаг `-s` включит HTTPS
- Остальные параметры будут взяты из `config.json` или значений по умолчанию
