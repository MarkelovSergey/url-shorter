# Linter - Статический анализатор exitcheck

Статический анализатор для Go, проверяющий использование критических функций выхода из программы.

## Возможности

Анализатор проверяет код на наличие:

1. **Использование встроенной функции `panic`** - сообщает о всех случаях использования `panic` в коде
2. **Вызов `log.Fatal`** вне функции `main` пакета `main`
3. **Вызов `os.Exit`** вне функции `main` пакета `main`

## Особенности

- Автоматически пропускает автогенерированные файлы (с комментарием `Code generated` или `DO NOT EDIT`)
- Использует `golang.org/x/tools/go/analysis/singlechecker` для запуска
- Покрыт тестами с использованием `golang.org/x/tools/go/analysis/analysistest`

## Установка и использование

### Сборка

```bash
go build -o linter ./cmd/linter
```

### Запуск проверки

```bash
# Проверка всего проекта
./linter ./...

# Проверка конкретного пакета
./linter ./internal/handler

# Проверка конкретного файла
./linter ./internal/handler/handler.go
```

## Тестирование

Запуск тестов анализатора:

```bash
cd cmd/linter/exitcheck
go test -v
```

## Структура

```
cmd/linter/
├── main.go                 # Точка входа с singlechecker
└── exitcheck/
    ├── analyzer.go         # Логика анализатора
    ├── analyzer_test.go    # Тесты
    └── testdata/           # Тестовые данные для analysistest
        └── src/
            ├── a/          # Тесты для обычных пакетов
            └── b/          # Тесты для пакета main
```

## Примеры

### Обнаруживается ❌

```go
package mypackage

import (
    "log"
    "os"
)

func Helper() {
    panic("error")          // использование встроенной функции panic
    log.Fatal("fatal")      // вызов log.Fatal вне функции main пакета main
    os.Exit(1)              // вызов os.Exit вне функции main пакета main
}
```

### Разрешено в main ✅

```go
package main

import (
    "log"
    "os"
)

func main() {
    // log.Fatal и os.Exit разрешены только здесь
    if err != nil {
        log.Fatal(err)  // ✅ OK
    }
    os.Exit(0)          // ✅ OK
}

func helper() {
    log.Fatal("error")  // ❌ Будет обнаружено
}
```

### Автогенерированные файлы игнорируются ✅

```go
// Code generated by mockery; DO NOT EDIT.

package mocks

func MockFunction() {
    panic("not implemented")  // ✅ Будет проигнорировано
}
```
